# Engenharia Biomédica UFRN — Redesign Profissional

Proposta de recriação institucional do site de Engenharia Biomédica da UFRN, desenvolvida em React + Vite + TypeScript.

## O que foi corrigido

- nova arquitetura da informação, orientada por tarefas e públicos
- homepage com proposta de valor clara
- navegação mais simples e responsiva
- central de graduação com calendário, documentos, estágio e TCC
- área de pesquisa com laboratórios e frentes acadêmicas
- diretório de pessoas com papéis institucionais bem definidos
- área editorial para informativos, oportunidades e comunicados
- hierarquia visual mais consistente
- melhor contraste, espaçamento, leitura e responsividade

## Como rodar

```bash
npm install
npm run dev
```

## Como gerar build

```bash
npm run build
npm run preview
```

## Observações

- Este projeto é uma recriação profissional baseada em informações públicas indexadas do curso e do SIGAA.
- O conteúdo foi reorganizado para demonstrar uma proposta de UX, conteúdo e interface mais clara, sem depender do site original para funcionar.
- Alguns links externos apontam para páginas públicas já existentes do ecossistema oficial da UFRN.
